# OceanFeed - Real-time Social Feed (React + Supabase)

Modern, minimalist feed-centric UI with Ocean Professional theme (blue + amber accents).
Built with React and Supabase for auth, database, and realtime.

## Quick Start

1) Configure environment variables (do not commit secrets):
- REACT_APP_SUPABASE_URL
- REACT_APP_SUPABASE_KEY

2) Install and run:
- npm install
- npm start

Open http://localhost:3000

## Features

- Authentication with magic link
- Real-time posts and comments
- Likes (via RPC), comment counts
- Profiles and user pages
- Moderation queue for pending content
- Ocean Professional theme with left nav, center feed, right suggestions
